# TUUUT

Bladmuziek-app voor de tablet: partituren per orkest, aantekenen met pen, metronoom, stemapparaat en snel opnemen. Werkt volledig offline na de eerste keer openen.

Installeren: open de app in Chrome op de tablet en kies **Toevoegen aan startscherm** / **App installeren**.
Partituren worden alleen op het toestel bewaard, niet in deze repository.

Notenweergave en transponeren van MusicXML: [Verovio](https://www.verovio.org) (LGPL-3.0).
